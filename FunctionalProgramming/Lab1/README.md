# Лабораторна робота №1 — варіант 6

**Інформаційна система «Індивідуальна робота кафедри зі студентами»**
Мова: Haskell (класи типів та екземпляри). СУБД: MySQL 8.4. Інтерфейс: веб-сторінки у браузері.

## Таблиці БД (8)

| Таблиця       | Зміст |
|---------------|-------|
| `teachers`    | викладачі (ПІБ, посада, ступінь, контакти) |
| `students`    | студенти (ПІБ, група, курс, контакти) |
| `topics`      | теми індивідуальної роботи: керівник, студент, терміни, статус |
| `schedule`    | графік роботи: консультації, перевірки, захисти |
| `assignments` | завдання та їх виконання: термін, стан, дата здачі, оцінка |
| `materials`   | допоміжні інформаційні матеріали до тем |
| `questions`   | питання студентів |
| `answers`     | відповіді викладачів |

## Класи та екземпляри

* `Model.Field.DbValue` — типи, що зберігаються в MySQL. Екземпляри: `Text`, `Int`, `Day`, `TimeOfDay`, `LocalTime`, `Maybe a`.
* `Model.Entity.Entity` — таблиця БД: назва, поля, перетворення запис ⇄ рядок, перевірка (`validate`, метод із реалізацією за замовчуванням).
  Екземпляри: `Teacher`, `Student`, `Topic`, `Schedule`, `Assignment`, `Material`, `Question`, `Answer` (`Model/Entities.hs`).
* `Model.Report.Report` — аналітичний звіт. Екземпляри: `StudentProgress`, `OverdueAssignments`, `OpenQuestions`, `UpcomingMeetings`, `TeacherLoad`.

Усі CRUD-операції (`Db.hs`) та сторінки (`Web/`) написані один раз для будь-якого типу з екземпляром `Entity`,
а екзистенційні типи `SomeEntity` / `SomeReport` дають змогу тримати різні сутності в одному списку.

## Можливості

* перегляд усіх таблиць, **введення** нових записів і **коригування/видалення** наявних;
* випадаючі списки для зовнішніх ключів, перевірка введених даних (обов'язкові поля, формати, бізнес-правила);
* **пошук** у кожній таблиці (зокрема за пов'язаними записами, наприклад завдання за прізвищем студента) та глобальний пошук по всій БД;
* звіти: успішність студентів, прострочені завдання, питання без відповіді (з кнопкою «Відповісти»), найближчі зустрічі, навантаження викладачів.

## Запуск

1. MySQL (один із варіантів):
   * портативний MySQL 8.4 (zip розпаковано в `%USERPROFILE%\mysql`):
     ```
     powershell -ExecutionPolicy Bypass -File scripts\start-mysql.ps1
     ```
   * або Docker: `docker compose up -d`
   * або будь-який MySQL 8: виконайте `sql/01_schema.sql`, потім `sql/02_seed.sql`.
2. Програма:
   ```
   stack run
   ```
3. Відкрийте http://localhost:3000

Параметри підключення можна змінити змінними середовища `MYSQL_HOST`, `MYSQL_PORT`, `MYSQL_USER`,
`MYSQL_PASSWORD`, `MYSQL_DATABASE`, а порт сервера — змінною `PORT`.

## Структура

```
app/Main.hs            точка входу
src/Model/Field.hs     типи полів, клас DbValue, розбір і форматування значень
src/Model/Entity.hs    клас Entity, SomeEntity
src/Model/Entities.hs  типи-записи предметної області та їх instance Entity
src/Model/Report.hs    клас Report та звіти
src/Db.hs              підключення до MySQL, узагальнені SELECT/INSERT/UPDATE/DELETE, пошук
src/Web/View.hs        HTML-сторінки (lucid)
src/Web/Server.hs      маршрути (scotty)
sql/                   схема БД і тестові дані
```
