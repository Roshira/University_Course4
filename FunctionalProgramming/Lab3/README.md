# Лабораторна робота №3 — варіант 6

**Обробка тексту підручника з програмування.** Надрукувати слова тексту в алфавітному порядку
за першою літерою; слова, що починаються з нової літери, друкувати з червоного рядка.
Мова: Haskell, лише `base`.

## Типи (`src/Text/Types.hs`)

* `Symbol` — символ: `Letter`, `Digit`, `Joiner` (апостроф/дефіс у слові), `Space`, `Punct`, `Other`;
* `Word` — слово (список символів);
* `Punctuation` — розділовий знак;
* `Token` — лексема речення: слово, розділовий знак або `Gap` (будь-яка кількість пробілів/табуляцій = один пробіл);
* `Sentence` — речення (пропозиція), `Text` — текст.

## Обробка

1. `Text.Parser`: символи класифікуються, групуються в лексеми (табуляції та послідовності пробілів → один пробіл),
   лексеми діляться на речення за `.`, `!`, `?`, `…` (крапка в `3.14` чи `obj.field` речення не завершує).
2. `Text.Task`: слова сортуються за абеткою без урахування регістру (цифри → латиниця → українська абетка
   з правильним місцем `ґ`, `є`, `і`, `ї`), групуються за першою літерою; кожна група — новий абзац
   з відступом (червоний рядок), довгий абзац переноситься по ширині.

## Запуск

```
stack run                              # файл data/textbook.txt
stack run -- мій_файл.txt --width 60   # інший файл, ширина рядка
stack run -- --all                     # з повтореннями слів (за замовчуванням — без)
stack run -- --quiet                   # не друкувати нормалізований текст
stack test
```
