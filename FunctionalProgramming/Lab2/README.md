# Лабораторна робота №2 — варіант 6

**Обмінне сортування зі злиттям Бетчера (odd-even merge sort) на k потоках.**
Мова: Haskell (GHC з ключем `-threaded`), лише `base` та `array`.

## Ідея

Сортування Бетчера — це сортувальна мережа: послідовність *етапів* `(p, k)`,
кожен з яких складається з незалежних компараторів `(a, a+k)` (порівняти й за потреби поміняти місцями).
Компаратори одного етапу не перетинаються, тому етап виконується паралельно:
діапазон позицій ділиться на `k` рівних частин, кожну обробляє окремий потік (`forkOn`),
а між етапами — бар'єр (очікування `MVar` від усіх потоків).
Кількість етапів — `log n · (log n + 1) / 2`, працює для довільного `n` (не лише степеня двійки).

## Запуск

```
stack run                    # інтерактивно: масив (або розмір випадкового) і k вводяться з клавіатури
stack run -- bench 1000000   # вимірювання часу для k = 1, 2, 4, ... на всіх ядрах
stack test                   # тести
```

Приклад інтерактивного запуску:
```
Введіть масив цілих чисел через пробіл (або порожній рядок — згенерувати випадковий): 5 3 9 -1 0 12 7 7 2
Кількість потоків k = 3
Відсортований масив: -1 0 2 3 5 7 7 9 12
Перевірка (збіг з Data.List.sort): OK
```

## Ефективність

Приклад `bench 1000000` на 2-ядерній машині (на машині з більшою кількістю ядер прискорення більше):

| k | час, с | прискорення |
|---|--------|-------------|
| 1 | 1.50   | 1.00 |
| 2 | 1.01   | 1.49 |
| 4 | 0.93   | 1.62 |

## Тести (`test/Spec.hs`)

* компаратори кожного етапу не перетинаються (коректність паралелізму);
* принцип 0-1: мережа сортує всі 0/1-масиви довжини до 14 ⇒ сортує будь-які масиви;
* 78 комбінацій розміру масиву та кількості потоків порівнюються з `Data.List.sort`;
* крайні випадки: відсортований, обернений, однакові елементи, від'ємні числа.

## Структура

```

app/Main.hs      інтерактивний режим і режим bench
test/Spec.hs     тести
```
