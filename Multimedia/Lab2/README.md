# Лабораторна робота 2, варіант 1 - Медіаплеєр

Desktop-застосунок для відтворення аудіо та відео з локальних файлів і за посиланням.

Мова: Python. Бібліотека: PySide6 (Qt 6, модулі QtWidgets, QtMultimedia, QtMultimediaWidgets).
Qt Multimedia використовує FFmpeg, тому окремо ставити кодеки не треба.

## Запуск

```
pip install -r requirements.txt
python main.py
```

Можна одразу передати файл або посилання: `python main.py samples/demo.mp4`

Тестові файли лежать у папці `samples`, їх можна створити заново командою
`python samples/generate_samples.py` (потрібні av та numpy).

Тести: `python -m unittest discover tests`

## Функціонал

- відкриття файлу (Ctrl+O), кількох файлів, папки, перетягування файлів у вікно
- Play / Pause (пробіл), Stop (S)
- перемотування вперед/назад на 10 секунд (стрілки вліво/вправо)
- попередній / наступний трек (PgUp / PgDn)
- progress bar - можна клікнути в будь-яке місце або перетягнути повзунок
- поточний та загальний час
- гучність (повзунок, стрілки вгору/вниз), вимкнення звуку (M)
- відкриття за URL (Ctrl+U), працюють звичайні посилання на mp4/mp3/webm і HLS (.m3u8)

Перевірені формати: аудіо - mp3, ogg, flac, wav; відео - mp4, webm, mkv.

Додатково:
- список відтворення, автоматичний перехід на наступний трек
- повтор (вимкнено / весь список / один трек), випадковий порядок
- збереження і відкриття списку у форматі m3u
- швидкість відтворення від 0.25x до 2x
- повноекранний режим (F, подвійний клік, Esc - вихід)
- для аудіо показується назва, виконавець і обкладинка, якщо є
- у рядку стану показуються роздільна здатність і кодеки
- темна тема
- налаштування (гучність, розмір вікна, список) зберігаються між запусками

## Структура

- `main.py` - запуск програми
- `media_player/utils.py` - форматування часу, перевірка URL і розширень
- `media_player/playlist.py` - список відтворення, режими повтору, m3u
- `media_player/player.py` - клас PlayerController, обгортка над QMediaPlayer
- `media_player/ui/main_window.py` - головне вікно
- `media_player/ui/widgets.py` - слайдер перемотування, відео, екран для аудіо
- `media_player/ui/theme.py` - тема оформлення
- `tests/test_core.py` - тести
- `samples/` - тестові медіафайли

Гучність зі слайдера переводиться у квадратичну залежність, бо людина сприймає гучність
нелінійно. Поки користувач тягне повзунок прогресу, позиція з плеєра не оновлюється,
перемотування відбувається після відпускання кнопки миші.
