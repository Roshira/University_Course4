# Лабораторна робота 3 - Стиснення зображень з втратами: DCT і DWT

Програма стискає зображення у відтінках сірого двома способами і показує результати поруч:
**Original | DCT | DWT** зі значеннями PSNR.

Мова: Python. Бібліотеки: NumPy (матриці), Pillow (читання/збереження зображень), PySide6 (інтерфейс),
matplotlib (лише графіки в `experiments.py`). Готові функції `dct()/idct()/dwt()/idwt()` не використовуються:
обидва перетворення реалізовані самостійно.

## Запуск

```
python -m pip install -r requirements.txt
python main.py                  # відкриється landscape.png
python main.py my_photo.jpg     # своє зображення (кольорове переводиться в сіре)
python experiments.py           # серія експериментів -> results/
python -m unittest discover tests
```

## Алгоритми

**DCT** (`imgcomp/dct.py`). Зображення зсувається на -128 і ділиться на блоки 8x8. Матриця DCT-II
`C[k, i] = a(k) * cos(pi * (2i + 1) * k / 16)`, `a(0) = sqrt(1/8)`, `a(k) = sqrt(2/8)`.
Пряме перетворення блоку `X = C B C^T`, обернене `B = C^T X C` (C ортогональна, тому `C^-1 = C^T`).
Множення виконується одразу для всіх блоків (масив форми `(64, 64, 8, 8)` для 512x512).

**DWT Хаара** (`imgcomp/haar.py`). Для пари сусідніх значень `L = (a + b)/sqrt(2)`, `H = (a - b)/sqrt(2)`;
обернене `a = (L + H)/sqrt(2)`, `b = (L - H)/sqrt(2)`. Один 2D-рівень: спочатку всі рядки, потім стовпці,
отримуємо підсмуги LL, HL, LH, HH. Наступний рівень обробляє лише LL. За замовчуванням 5 рівнів.
Те саме можна записати матрично `W A W^T` (`haar_matrix`), тести перевіряють, що результати збігаються.
Перед DWT зображення теж зсувається на -128, щоб умови для обох методів були однакові.

**Стиснення** (`imgcomp/compress.py`), три механізми, однакові для обох методів:

| Механізм | Що робить | Параметр |
|---|---|---|
| Частка найбільших коефіцієнтів | залишає N·p найбільших за модулем коефіцієнтів, решту обнуляє | p = 0.1 % ... 100 % |
| Поріг | обнуляє коефіцієнти з `|c| < T` | T = 0 ... 200 |
| Квантування | `c' = round(c / q) * q` | q = 1 ... 200 |

Обидва перетворення ортонормовані, тому похибка в коефіцієнтах дорівнює похибці в пікселях
(теорема Парсеваля), і порівняння DCT та DWT за однакових параметрів чесне.

**Метрики** (`imgcomp/metrics.py`):
- `PSNR = 10 log10(255^2 / MSE)` між оригіналом і відновленим зображенням (після округлення до 0..255);
- коефіцієнт стиснення за коефіцієнтами = усього коефіцієнтів / ненульових;
- оцінка реального розміру: цілі коефіцієнти (округлені або індекси квантування) записуються як int16
  і стискаються zlib. Цей розмір залежить не лише від кількості ненульових коефіцієнтів, а й від їх
  величини та розташування, тому два коефіцієнти стиснення відрізняються.

## Інтерфейс

- три панелі Original | DCT 8x8 | DWT Хаара, під кожною PSNR, кількість/частка коефіцієнтів, оцінка розміру;
- механізм стиснення і його рівень (повзунок), кількість рівнів Хаара;
- режими перегляду: відновлене зображення, карта коефіцієнтів після стиснення (для DWT з межами підсмуг),
  різниця з оригіналом (x5);
- синхронне масштабування і зсув в усіх панелях (колесо миші, перетягування, подвійний клік - вписати);
- графік PSNR від частки збережених коефіцієнтів для обох методів з поточною точкою;
- таблиця експериментів: «Додати в таблицю», «3 рівні стиснення» (10 %, 5 %, 1 %), експорт CSV;
- відкриття будь-якого зображення, вбудовані тестові зображення, збереження результатів (Ctrl+S).

## Тестові зображення (`samples/`)

Усі зображення 512x512 створені власним скриптом `python samples/generate_samples.py`
(фрактальний шум і малювання фігур, генерація детермінована):

- `landscape.png` - гірський пейзаж: небо з хмарами, сонце, гори, озеро з відображенням, трава, ялина;
- `city.png` - нічне місто: будинки з вікнами, місяць, зорі (однорідні області й різкі краї);
- `marble.png` - мармур і дерево (дрібна природна текстура);
- `test_pattern.png` - градієнт, краї, тонкі лінії, смуги різної частоти, текст, шум.

## Результати (`results/`, створює `experiments.py`)

- `results.md`, `results.csv` - усі експерименти: 4 зображення x 3 механізми x 4-5 рівнів x 2 методи;
- `levels.md` - вплив кількості рівнів Хаара;
- `*_psnr.png` - графіки PSNR від частки коефіцієнтів;
- `*_keep_*.png` - Original | DCT | DWT для 20 %, 10 %, 5 %, 2 %, 1 % коефіцієнтів.

Приклад (частка найбільших коефіцієнтів, PSNR у дБ):

| Зображення | Збережено | DCT | DWT |
|---|---|---|---|
| landscape | 10 % | 41.67 | 46.19 |
| landscape | 5 % | 36.90 | 38.94 |
| landscape | 1 % | 24.22 | 31.04 |
| city | 10 % | 41.60 | 72.64 |
| city | 5 % | 32.29 | 55.36 |
| city | 1 % | 14.27 | 24.42 |
| marble | 10 % | 40.51 | 36.96 |
| marble | 5 % | 35.53 | 33.16 |
| marble | 1 % | 20.21 | 25.70 |

DWT Хаара краще на зображеннях з однорідними областями і різкими краями (city, landscape),
DCT - на текстурах (marble, test_pattern). При 1 % і менше DCT різко гіршає: 1/64 = 1.56 % -
це один коефіцієнт на блок 8x8.

## Структура

- `main.py` - запуск програми
- `experiments.py` - серія експериментів без інтерфейсу
- `imgcomp/dct.py` - матриця DCT, блоки 8x8, пряме/обернене DCT
- `imgcomp/haar.py` - пряме/обернене перетворення Хаара, підсмуги
- `imgcomp/compress.py` - механізми стиснення, повний цикл для DCT і DWT
- `imgcomp/metrics.py` - MSE, PSNR, коефіцієнт стиснення, оцінка розміру
- `imgcomp/visualize.py` - карти коефіцієнтів і різниці
- `imgcomp/image_io.py` - читання/збереження, підготовка розміру
- `imgcomp/ui/` - головне вікно, віджети, тема
- `tests/` - unit-тести (31)
